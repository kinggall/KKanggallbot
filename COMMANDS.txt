깡갤봇 명령어 안내
==================

일반 명령어
-----------

!도움말
사용 가능한 명령어 목록을 확인합니다.

!히든
일반 도움말에서 숨긴 다음 6개 명령어를 보여줍니다.
!월간원정 / ![함선명]팬티 / ![닉네임]아내 / !개구리야 / !미르야 / !단발퀘
기능은 그대로 사용 가능하며, 이 문서에는 숨긴 명령어의 상세 설명도 포함합니다.

!내아내 / ![이름]아내
랜덤 칸무스 한 명의 이름을 보여줍니다. 개장형은 별도로 추첨하지 않습니다.

!공지
공지사항 링크를 보여줍니다.

!통합공략
칸코레 통합공략 링크를 보여줍니다.

!단발퀘
칸코레 단발 퀘스트 공략 링크를 보여줍니다.

!반복퀘
칸코레 반복 퀘스트 공략 링크를 보여줍니다.

!멘테
점검 관련 링크를 보여줍니다.

!월간원정
도움말 목록에는 표시하지 않지만 기존 링크 명령은 계속 사용할 수 있습니다.
월간 원정 공략 링크를 보여줍니다.

!이벤트
현재 이벤트 정보를 보여줍니다.

!개구리야
개구리의 전역일을 보여줍니다.

!미르야
미르의 전역일을 보여줍니다.

!전과 5 / !전과 20 / !전과 100 / !전과 500
Senka Viewer에서 20개 서버의 해당 순위 전과를 보여줍니다.
사이트 갱신이 늦은 서버는 점수 뒤에 (미갱신)으로 표시합니다.

!경험치 [현재레벨] [목표레벨] [판당경험치(선택)]
함선이 현재 레벨에 막 도달한 시점부터 목표 레벨까지 필요한 경험치를 계산합니다.
예: !경험치 1 99 / !경험치 80 99 1500
판당 경험치를 입력하면 필요한 횟수를 올림 계산합니다. 생략하면 필요 경험치만 표시합니다.
판당 경험치는 배율이 반영된 해당 함선의 실제 획득량을 입력합니다.
입력 범위 Lv1~188. Lv100 이상은 결혼(가)이 필요합니다.

!원정 [번호]
원정 시간, 월간·교전형, 편성·레벨·스탯·필수 드럼통 조건, 보상과 선행조건을 보여줍니다.
예: !원정 B4 / !원정 b4 / !원정 38
여러 선행조건을 +로 연결하면 모두 필요합니다. 최초 1회와 매월 조건도 구분합니다.
0인 자원은 생략합니다. 반짝이·대성공 확률·대발 보너스는 계산하지 않습니다.
저장된 자료만 읽으며 명령어 입력으로 외부 사이트에 접속하지 않습니다.
자료 출처는 EXPEDITION_DATA.md, 추가 교차검증은 EXPEDITION_CROSSCHECK.md, 전체 출력은 EXPEDITION_PREVIEW.txt에서 확인할 수 있습니다.

함선·장비 검색
---------

!신규임무
최근 점검으로 추가된 임무 번호와 한국어 제목을 표시합니다.
상세 조건·보상은 !임무 [번호]로 확인합니다.
검토된 신규 임무 데이터의 가장 최근 구현일을 기준으로 목록을 갱신합니다.

!공략 [해역/임무번호]
PC에 수집된 제카마시 공략의 편성 사진과 해역별 경로를 보여줍니다.
예: !공략 By10 / !공략 2610B1
특정 해역의 편성: !공략 By10 55 (5-5와 동일)
일반해역: !공략 55 / !공략 5-5
루트 선택: !공략 55 루트1 / !공략 55 중앙
사진만 설명된 공략은 '편성은 이미지 참조'로 표시하며 편성을 추측하지 않습니다.
공략 미등록·구공략·연결 검토 필요는 구분해서 안내합니다.

!임무 [번호/키워드]
예: !임무 B44 / !임무 수상반격
검색 실패 안내 예: !임무 B44 / 반격 / 6구 / 찐빵
임무 번호는 대소문자를 구분하지 않습니다. 임무명은 공백 없이도 검색할 수 있습니다.
임무명 검색 결과가 1개면 상세 내용, 여러 개면 이름과 외부 번호 목록을 보여줍니다.
예: !임무 증강 → 후보 목록. !임무 해상호위총대 → B100/D23 두 후보.
함선명/별명으로 제목과 함선 조건을 함께 검색합니다. 예: !임무 뽀이 / !임무 베이
전대 약칭도 검색합니다. 예: !임무 15구 / !임무 4수전 / !임무 1항전 / !임무 18전대
등록된 인물의 성/이름/별칭으로 연결된 함선들의 임무를 모아 검색합니다. 예: !임무 나구모 / !임무 기무라 / !임무 다몬마루
단발·일간·주간·월간·계간·연간·기간한정, 조건, 확정/선택 보상, 선행조건과 후속임무를 표시합니다.
제1함대 지정은 생략하고 다른 함대 지정만 표시합니다. 날짜 지정 일간은 출현 날짜를 표시합니다.
선행조건의 +는 모두 충족해야 한다는 뜻입니다. 후속임무에는 다른 선행조건이 더 있을 수 있습니다.
미검증 표시가 있는 임무는 마지막에 '※ 조건 등을 검증중인 임무입니다.'를 표시합니다.
위키와 기존 선행임무 정보가 다르면 [선행임무](검증중)으로 표시합니다.
선행임무/후속임무가 미등록이면 해당 부분은 생략합니다.
종료된 임무는 키워드 검색에서 제외하며 정확한 임무 번호로만 조회할 수 있습니다.
저장된 자료를 사용하며 명령어마다 외부 사이트에 접속하지 않습니다. 자료 범위와 검증 기록: QUEST_DATA.md.

!한정드랍
칸로그 레어 함선 목록에서 '期間限定' 표시가 있는 함선만 함종별로 보여줍니다.
함선의 드랍 위치와 확률은 !드랍 [함선명]으로 확인합니다.

!드랍 [해역/함선명]
일반 해역 37곳의 유니크·레어·기간한정 함선 드랍률을 S/A 각각 보여줍니다.
!드랍 5-5 / !드랍 55는 같은 명령입니다. 기본은 최종 보스입니다.
!드랍 5-5 S / !드랍 5-5 A
해당 승리 등급만 보여줍니다.
!드랍 5-5-P / !드랍 5-5-P S / !드랍 5-5-P A
P마스를 지정합니다. 다른 마스도 해당 문자로 지정할 수 있습니다.
!드랍 55p / !드랍 55p S처럼 대시를 생략할 수 있으며 영문 대소문자는 구분하지 않습니다.
!드랍 7-5-1처럼 복수 보스 차수를 지정할 수 있습니다.
1-6에는 보스가 없어 !드랍 16b처럼 마스를 지정합니다. 명령어 입력은 외부 접속을 발생시키지 않습니다.

!칸무스 [함선명]
개장 형태별 능력치, 다음 개장 레벨과 확인된 개장 재료를 보여줍니다. 확인된 재료가 없으면 재료 줄을 생략합니다.

!개수 [장비명/2번함]
단계별 개수 비용·소모 장비·특수재료, 2번함과 요일, 변환 결과를 보여줍니다.
예: !개수 93식수중청음기 / !개수 콜세어 1D / !개수 #573
함선명이나 함선 별명이 정확히 일치하면 2번함으로 지정했을 때 개수 가능한 장비를 장비별·요일별·개장형태별로 보여줍니다. 예: !개수 이세 / !개수 이세개2. 장비명·장비 별명이 정확히 일치하면 장비 검색이 우선입니다.
!장비와 같은 별명·축약명·번호 검색을 지원합니다. 여러 후보가 있으면 번호로 선택합니다.
재료가 같은 연속 단계는 ★0~5처럼 묶고, 달라지면 ★6 / ★7~8 / ★9처럼 나눕니다.
★숫자는 작업 전 단계입니다. ★9 비용은 ★9→★max, ★max 비용은 장비 변환 비용입니다.
비용은 '자재 X/나사 Y (확정 시 A/B)'로 표시하고, 소모 장비·특수재료는 다음 줄의 ' · 소모아이템 :'에 적습니다.
특수재료와 공창자원 등은 해당 단계 기본 비용에 더해 표시합니다.
자원(연료·탄약·강재·보키)은 표시하지 않습니다. 개수 지원함은 '○ 2번함'으로 표시합니다.
같은 함선 계보에서 요일이 같은 개장형은 '시구레[미개장/개1] (금토일)'처럼 묶습니다.
2번함에 따라 일반 개수 재료가 다르면 개수 경로를 나눠 표시합니다.
변환별로 소모 재료·결과 장비의 ★·2번함·요일을 따로 표시합니다. 변환이 하나면 번호를 생략합니다.
원본에 정보가 없는 장비는 '개수 정보 없음', 2번함·요일이 비어 있는 경로는 '○ 2번함' 아래 ' - 정보 없음'으로 표시합니다.
데이터 출처·기준 버전과 검증 내용은 IMPROVEMENT_DATA.md를 참고하세요.

!레시피 함선이름 연료/탄약/강재/보크사이트
입력한 함선을 비서함으로 사용했을 때 개발 가능한 모든 장비의 확률과 실패율을 보여줍니다.
예: !레시피 리슐리외 10/30/20/10 / !레시피 테루즈키 10/30/20/10
함선 별명도 지원합니다. 예: !레시피 리슐 10/30/20/10 / !레시피 푸릉이 10/30/20/10
자원은 각각 10~300 사이의 정수로, /로 구분합니다.
함종·함급·특정 함선 조건에 따라 개발 그룹을 자동으로 찾습니다.
아키즈키급 함선들은 같은 함급 그룹으로 연결됩니다. 표시되는 그룹명은 원본 개발 분류입니다.
미개장 이름이나 기본 별명은 그 형태로 계산합니다. 개장형은 명시해주세요.
예: !레시피 히에이 개2 10/30/20/10 / !레시피 불고기 개2 10/30/20/10
일본어 이름이 동일한 여러 형태는 첫 형태를 기본값으로 사용하며, 함선 ID로 형태를 지정할 수도 있습니다.
예: !레시피 #645 10/30/20/10 (소야 등대보급선)
소야는 형태 이름으로도 선택할 수 있습니다: !레시피 소야 특무함 20/20/20/20
!레시피 소야 등대보급선 20/20/20/20 / !레시피 소야 남극관측선 20/20/20/20
기본 '소야'는 특무함입니다. 등대보급선과 남극관측선은 개발 확률이 같고 특무함과는 다릅니다.
휴가와 이세의 특수 개발 그룹은 원본 데이터에서 개·개2 양쪽을 포함하므로 '개/개2'로 표시합니다.
장비별 최소 자원에 미달하거나 확률이 0인 장비는 생략합니다. 실패율은 맨 마지막에 표시합니다.
기존 함선 도감 866개 형태의 함종·함급·개장 관계를 사용하며 사이트에는 접속하지 않습니다.

!개발 장비이름
장비 개발 레시피의 최상위 결과를 [최적]으로 보여줍니다.
특정 함선·함급 등이 필요한 결과라면 해당 조건 없는 [범용] 레시피도 최대 1개 표시합니다.
최적과 범용의 자원·개발 확률·실패율이 모두 같으면 범용을 [최적]으로 한 번만 표시합니다.
자원 순서: 연료 / 탄약 / 강재 / 보크사이트.
개발 확률 우선, 자원 합계가 적은 순서입니다. 합계 차이가 1 이하면 실패율 높은 순서입니다.
실패율은 다른 장비가 나오는 경우를 제외한 개발 자체의 실패 확률입니다.
예: !개발 즈이운 / !개발 41cm연장포 / !개발 영전 21형 / !개발 #7
!장비와 같은 이름·별명 검색을 사용합니다. 여러 후보가 있으면 장비 목록과 번호를 안내합니다.
예: !개발 와일드캣 → 후보 목록 → !개발 #197
개발할 수 없는 장비는 장비명과 '· 개발불가'를 보여줍니다.
사이트에 접속하지 않고 저장소에 포함한 kc-development-tools 데이터로 계산합니다.
데이터 출처·기준 버전·라이선스는 DEVELOPMENT_DATA.md와 THIRD_PARTY_NOTICES.md를 참고하세요.

!장비 장비이름
장비의 0이 아닌 기본 능력치와 사거리 / 배치코스트 / 행동반경을 보여줍니다.
배치코스트 옆에는 기지 항공대 최대 편대 기준 보키 소모량을 표시합니다. 예: 배치코스트 12(보키 216)
예: !장비 12cm단장포 / !장비 영식 함상전투기 21형 / !장비 #1
장비 별명은 data/equipment_aliases.json에서 일본어 장비명 뒤의 목록에 추가합니다.
함재기 별명 예: !장비 와일드캣 / !장비 헬캣 5N / !장비 플라잉팬케이크
주포는 cm와 포를 생략할 수 있습니다. 예: !장비 12단장 / !장비 46삼연장
공백·대소문자·라틴 문자 악센트를 무시하며 한국어명·일본어명으로 검색할 수 있습니다.
여러 장비가 검색되면 최대 10개 후보와 ID를 안내합니다. 심해 장비는 제외합니다.
음수 능력치도 표시하며, 사거리·배치코스트·행동반경이 0이면 생략합니다.
기본 능력치가 전부 0이면 '능력치 없음'으로 표시합니다. 특수 효과가 없다는 뜻은 아닙니다.
응급수리요원·응급수리여신에는 1회 부활 설명을 표시합니다.
사거리 코드는 단 / 중 / 장 / 초장 / 초장+로 표시합니다.
피트·개수강화 수치는 더하지 않은 장비 자체의 기본값입니다.

!칸무스 함선이름
함선의 모든 개장 단계와 최대 능력치를 보여줍니다.

!초기장비 함선이름
개장형별 초기 장비를 보여줍니다. 함선 별명도 사용할 수 있습니다.
예: !초기장비 유바리 / !초기장비 아마츠카제 / !초기장비 불고기
동일한 장비를 여러 개 가져오면 개수만큼 각각 표시합니다.
개수 장비는 장비명 뒤에 ★7처럼 표시하고, 초기 장비가 없는 형태는 '초기 장비 없음'으로 표시합니다.
개장형 이름은 !칸무스와 동일하게 표시하며, 이름이 바뀌는 함선도 전체 계보를 보여줍니다.
CSV에 없는 개수 수치와 ??? 슬롯은 ID·슬롯이 확인된 공개 자료로 보완합니다. 상세 출처는 INITIAL_EQUIPMENT_DATA.md를 참고하세요.

!슬롯 함선이름
함선의 개장 단계별 항공기 슬롯별 탑재량을 보여줍니다.
예: 18 / 18 / 45 / 12. 중간의 0도 그대로 표시합니다.
항공기를 장착할 수 없는 함선은 장착 불가로 표시합니다.
장착은 가능하지만 탑재량이 모두 0인 형태는 별도로 안내합니다.

!피트 함선이름
개장형별로 추가 능력치가 생기는 장비와 동시 장착 조건을 보여줍니다.
예: !피트 콩고 / !피트 불고기
전체 결과를 한 메시지로 표시합니다. 전 형태에 동일한 장비 보너스만 [전체]로 묶습니다.
나머지는 최종 개장형부터 역순으로 표시하고, 일부 형태끼리 같은 보너스도 각 형태에 반복합니다.
1개당: 장비 개수만큼 적용합니다.
2개 이상 장착: 추가 수치는 해당 장비를 총 2개 이상 장착하면 한 번 더해집니다.
3개 이상 장착 조건도 있으면 2개 조건과 함께 누적됩니다.
★조건: 해당 ★ 이상인 장비만 그 줄의 개수 조건에 포함됩니다. ★조건별 보너스는 누적됩니다.
수상전탐·대공전탐·고명중전탐 및 특정 장비의 동시 장착 조건을 함께 표시합니다.
전탐 기준은 기본성능의 색적 5 이상 / 대공 2 이상 / 명중 8 이상입니다.
장비 기본 능력치와는 별개인 74식 등록 보너스를 안내합니다. (1회만)은 한 번만 적용한다는 뜻입니다.
동시 장착 장비의 ★조건은 해당 장비명 다음에 들여쓴 하위 줄로 표시합니다.

예시:
!칸무스 후부키
!칸무스 베아른
!칸무스 U-511
!칸무스 로-500
!슬롯 카가

개장으로 이름이 바뀌는 함선은 같은 계보로 표시됩니다.

예시:
U-511 = 로500
히비키 = 베르니
유키카제 = 단양 = 유키카제 개2
