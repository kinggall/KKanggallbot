# 주식봇 코드 동기화

코드 수정·검증 → GitHub 커밋/푸시 → `scripts/sync_drive_data.py push --root /workspace --include KKanggallbot/stockbot` → PC의 기존 자료 감시가 해시 검증 후 Git fast-forward 적용합니다.

커밋된 Python 파일만 원래 경로에 개별 게시하며 schema 3 목록에 커밋과 해시를 기록합니다. 인증 파일·DB·개인 데이터·캐시·미커밋 파일은 게시하지 않습니다. 로컬 수정이나 이력 분기는 강제로 덮어쓰지 않습니다. Git 감시가 먼저 새 커밋을 받으면 이전 Drive 코드로 되돌리지 않습니다.

동기화와 봇 감시 스크립트 자체를 바꾼 경우에만 기존 두 감시 창을 Ctrl+C로 종료하고 Git pull 후 다시 실행합니다. Iris는 유지합니다. 일반 명령어 수정은 기존 자동 동기화·봇 감시가 적용합니다.

공용 사용방법·일반 도움말·대문에는 주식 명령어를 추가하지 않습니다. 사용자 안내는 `!주갤`, 관련 문서와 검증 도구는 이 폴더에만 둡니다.
