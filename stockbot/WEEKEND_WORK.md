# !주말출근

Drive의 Domino_Overview_Private_Snapshot.html에서 `총투자수익` 표시값을 읽는다.
기존 보유/실현손익을 임의 합산하지 않는다. 태그를 제거한 본문에서 정확한
라벨 다음의 원화 금액만 허용하며, 값 누락·상충·인증 실패 시 오류를 안내한다.
HTML의 스크립트·스타일은 실행하거나 값으로 사용하지 않는다.

- 손실: abs(총투자수익) / 150,000원을 올림한 횟수, 횟수 / 20년.
- 출력은 `✔️ 주말출근: 13.5년` 한 줄. 금액·횟수는 공개하지 않는다.
- 횟수를 먼저 올림한 뒤 연수를 소수 첫째 자리 반올림(ROUND_HALF_UP).
- 정수는 소수점 생략: -3천만원은 10년, -2천만원은 6.7년.
- 양수: `✔️ 주말출근: 왜 함?`만 응답.
- 0원: `✔️ 주말출근: 0년`.
- !주갤에만 안내하며 일반 깡갤봇 도움말에는 추가하지 않는다.
- 매 요청마다 최근 게시된 overview를 읽는다. 거래소 실시간 자료가 아니다.
- KAKAO_STOCK_OVERVIEW_FILE_ID로 overview Drive 파일 ID를 변경할 수 있다.

모의 검증은 완료했으나 클라우드 Drive 인증 오류로 실제 overview 파싱 및
PC 카카오톡 응답은 미검증이다. 인증 복구 후 실데이터 검증이 필요하다.
