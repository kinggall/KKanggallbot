# 주식 명령어와 검증

이 기록은 GitHub 대문이나 깡갤봇 일반 도움말에 추가하지 않습니다.
주식 도움말은 `!주갤`로 표시합니다. `!투자`와 `!수익률` 명령어는 제거했습니다.
도움말에 보유/평가/실현이 정달봄의 실제 거래 기록이라는 안내를 표시합니다. 깡갤봇 도움말처럼 제목 뒤
U+200B 4000개와 구역별 구분선을 사용합니다. 실제 전체보기 표시는 카카오 클라이언트에
따라 달라질 수 있습니다. 실제 자산 JSON·인증·검증 응답은 저장하지 않습니다.

## 명령어

주가 검색 순서는 등록 별명/미국 한글명 → 정식명·티커 정확 일치 → 국내 이름 앞부분
일치 → 국내 이름 부분 일치입니다. 각 단계에서 유일한 종목만 자동 조회하며 다중 후보는
`종목명·티커로 입력해 주세요.`와 목록을 표시합니다. 유사도/오타로 임의 선택하지 않습니다.
`aliases.py`에서 별명을 관리합니다. 구글은 알파벳 A(GOOGL), 버크셔는 B주로 명시해
국내 유사 이름 ETF보다 우선하며, 알파벳 C/버크셔 A는 별도 구분합니다. 미국 티커 직접
검색도 유지합니다. 한글명은 등록한 종목만 지원하며 모든 미국 종목 번역 사전은 아닙니다.
버크셔의 점·하이픈·슬래시 클래스 표기는 한투 형식 `BRK/A`, `BRK/B`로 통일합니다.

### 국내 별명 확장 검토

`DOMESTIC_GROUPS`에 사용자 지정 별명 96개(77묶음)를 추가했습니다. 원래 정식명인
씨젠·엔켐·천보·기아·풍산·하이브·CJ ENM 등은 기존 정확 검색으로 처리합니다.
새 별명은 종목코드를 하드코딩하지 않고 기존 public listing catalog의 정식명과 정확히
대조합니다. 현재 상장 목록에 대상이 없으면 임의 종목이나 미국 티커로 대체하지 않습니다.
HLB/KB/LGD/JYP/HSD 등 영문 국내 별명도 미국 티커보다 먼저 처리합니다.

- 삼스: 삼성에스디에스. 삼성SDI는 삼SDI/삼에스디아이로 분리.
- 삼엔: 삼성E&A/에스엠 충돌이므로 둘 다 상장되어 있으면 선택 목록.
- HD현중/코스모: 서로 다른 회사가 대상이므로 선택 목록.
- 네패스/원익: 네패스아크/원익IPS와 별개 상장사. 원래 회사도 후보에 포함.
- 신한/신풍 등 실제 정식명과 충돌하는 경우에도 정확 이름 후보를 버리지 않음.
- 우금지: 우리금융지주.
- 사명 변경은 목록에 존재하는 현 명칭을 사용. 삼성엔지니어링→삼성E&A,
  레고켐바이오→리가켐바이오 등 이전 표기는 조회 대상 대조에만 사용.
- `우` 접미사는 실제 상장 우선주 이름(우/숫자우B 등)만 매칭. 전체 이름 정확 일치가
  먼저이므로 회사명이 우로 끝나도 무조건 잘라내지 않음. 종류가 여럿이면 선택 목록.

최신 공개 마스터/네이버 사이트는 이 클라우드의 프록시에서 차단되어 실접속 대조를
완료했다고 주장하지 않습니다. 자동 테스트는 전체 별명 매핑·충돌·우선주·미상장 거부를
가상 목록으로 검사했습니다. 실명/코드 대조는 PC의 최신 또는 캐시된 listing에서 수행됩니다.
PC에서 시세 호출 없이 목록 전체를 대조하려면 다음을 실행합니다.

```powershell
C:\KakaoBot\.venv\Scripts\python.exe -m stockbot.verify_aliases
```

- `!주가 두산에너빌리티`: 한투 국내 통합 시세. 화면에는 `통합` 표시.
- `!주가 DRAM` / `!주가 AAPL`: 미국 NAS/NYS/AMS만 조회. 영문 티커를 국내 부분검색보다 우선합니다.
- `!보유`: 국내 종목명(코드), 미국 티커(정식 종목명). 수량·계좌는 표시하지 않으며
  같은 종목의 계좌별 중복을 제거합니다. 하단에는 한국시간 기준 갱신 날짜만 표시합니다.
  미국 이름이 티커로만 저장되어 있으면 NasdaqTrader 공개 종목 목록에서 정식명을
  조회합니다(전체 공개 목록 요청, 개인 보유정보는 외부로 전송하지 않음). 공개 이름은
  하루 동안 메모리에 보관하며 확인 불가는 `종목명 미확인`으로 표시합니다.
  VOO는 제공된 예시의 정식명을 기본값으로 유지합니다. 클라우드에서는 공개 목록
  사이트가 네트워크 프록시에서 차단되어 실접속 검증은 PC에서 필요합니다.
- `!평단 삼성전자`: `[삼성전자]` 아래 평균 매입가·수익률·현재가·전일대비를 표시.
- `!실현`: `[실현 수익률]` 아래 `종목명(티커)` 목록. 보유 목록과 같은 형식으로
  종목별 중복을 제거하며 수익률·계좌·손익 금액·상세 명령어 문구는 목록에 넣지 않습니다.
  티커는 실현 JSON → 같은 보유 종목 → 공개 상장 목록의 정확한 정식명 대조 순으로
  찾습니다. 유일한 티커를 확인할 수 없으면 `코드 미확인`으로 표시합니다.
  미국 항목은 보유와 동일하게 티커(정식명) 형식을 사용합니다.
- `!실현 [종목명/티커]`: 종목명, ▲/▼ 실현 수익률(소수점 두 자리), 최종 거래일, 갱신 날짜 표시.
  실현 기록에 티커가 없으면 보유 종목의 티커/이름 또는 공개 상장 목록에서 이름을 대조합니다.
  최종 거래일은 JSON `last_trade_date`를 사용하며 없거나 잘못된 날짜는 `미확인`입니다.
  여러 계좌/기간 기록은 각 기록의 수익률과 최종 거래일을 따로 유지합니다.

`unlisted.py`의 `UNLISTED_NAMES`에 확인된 비상장 회사명을 추가하면 `!보유`에서
`회사명(비상장)`으로 표시합니다. 현재 오아시스만 지정했습니다. 다른 코드 미확인 종목을
무조건 비상장으로 분류하지 않으며, 향후 상장하면 해당 이름을 목록에서 제거합니다.

사용자 요청으로 모든 방에서 자산 명령어를 허용합니다. 명령어를 아는 다른 사용자도
조회할 수 있습니다. 계좌명·내부 account_id·손익 금액은 출력하지 않습니다.
서로 다른 계좌·기간·통화 수익률을 합산하거나 재계산하지 않습니다.

## Drive와 시간

`portfolio.py`는 Domino JSON을 Drive에서 읽기만 합니다. UTF-8로 명시적으로 해석하며
메모리 캐시 30초 외에는 보관하지 않습니다. 캐시 만료 후 읽기에 실패하면 이전 값을
새 자료로 내보내지 않습니다. 하단은 한국시간 기준 `갱신 일자: YYYY-MM-DD`로 통일하며
평단 통합 화면에는 `시세 기준: YYYY-MM-DD`를 추가합니다. 계좌별 행을 재계산하거나
합산하지 않고 그대로 유지하되 계좌명·기간·원본 타임스탬프는 표시하지 않습니다.

평단/보유 수익률은 Domino 스냅샷 값을 유지합니다. 현재가와 전일대비는 동일한 한투
응답을 사용합니다. 따라서 수익률은 Domino 갱신 시점 기준이며 한투 조회 시점 가격으로
재계산한 수익률이 아닙니다. `갱신 일자`는 Domino 생성일, `시세 기준`은 한투 조회일입니다.
한투 실패 시 JSON의 현재가(가용한 경우)와 그 기준일로 돌아가고 전일대비는 `미확인`입니다.
전일종가가 없을 때 0원/0%를 꾸며내지 않습니다. 국내는 통합, 미국은 기존 미국 조회를
이용하며 양쪽 모두 5초의 메모리 캐시를 사용합니다.

PC는 기존 `cloud/token.json`을 사용하며 `KAKAO_STOCK_DRIVE_TOKEN_FILE`로 변경 가능합니다.
클라우드는 기존 GOOGLE_DRIVE OAuth 환경변수를 사용합니다.
다른 JSON을 사용할 경우 `KAKAO_STOCK_PORTFOLIO_FILE_ID`를 설정합니다.

국내 시간대: 평일 08:00–08:50 NXT 프리, 09:00–15:30 정규장,
16:00–20:00 NXT 애프터. 미국 시간대는 뉴욕 기준 프리/정규/애프터이며 DST를 적용합니다.
시간대 표시는 실제 휴장 여부, 거래정지, NXT 대상 여부 또는 장외 시세의 수신을 보증하지
않습니다. 조회시각은 거래 체결시각이 아닙니다. 사용자 요청으로 응답 하단의 주의 문구와
`최근 시세` 문구는 표시하지 않으며, 거래소 코드는 나스닥/뉴욕/아멕스로
풀어 표시합니다.

## 검증

```sh
python -m unittest discover -s stockbot -p 'test_*.py'
python -m unittest discover -s tests
```

자동 검증은 가상 데이터만 사용하며 실제 카카오 메시지를 전송하지 않습니다.
실제 Drive JSON의 모든 보유/실현 종목 렌더링도 확인했습니다(개인 수치는 출력·저장하지 않음).
기존 테스트 327개와 별도 stockbot 테스트를 실행합니다.

한투 PC 모듈과 인증은 클라우드에 없으므로 실제 통합·미국 시세 성공은 별도 PC 검증이
필요합니다. 첨부된 실제 모듈에서 DOMESTIC/OVERSEAS는 문자열 경로이고, query가
ALLOWED 표에서 TR ID를 선택하는 것을 확인했습니다. 해외 조회에는 설치된 OVERSEAS
`/uapi/overseas-price/v1/quotations/price-detail` 경로를 그대로 전달합니다.
DOMESTIC 구조를 추측해 경로/TR ID를 치환하던 초기 연결 방식은 제거했습니다.
실제 모듈의 Client.query를 가상 전송으로 검사하되, 실제 한투 실조회와 구분합니다.

PC에서 아래 명령은 자산 값이나 시세 값을 출력하지 않고 성공 여부만 검사합니다.
카카오 메시지를 보내거나 Domino DB를 수정하지 않습니다. 실패 시 종료코드는 1입니다.

```powershell
C:\KakaoBot\.venv\Scripts\python.exe -m stockbot.verify
```

저장소 루트에서 실행합니다. 미국 조회를 위한 시세 권한/계약·지연 여부는 한투 설정에
따릅니다. 외부 Domino 저장소는 수정하지 않습니다.
