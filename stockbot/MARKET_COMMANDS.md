# 시장 지표 명령어

사용자 안내는 !주갤과 stockbot 폴더에만 둡니다. 공용 사용방법·대문에는 추가하지 않습니다.
값 다음 줄은 공백 3개를 들여씁니다. !금리 제목은 [국채 금리]이며 전부 실패해도 유지합니다.

| !국내지수 | 코스피·코스닥·코스피200 | 한투 우선(0001/1001/2001), 실패 시 Yahoo |
| !미국지수 | S&P500·나스닥종합·다우 | Yahoo |

| !코인 | BTC·ETH·XRP 실제 USD 페어 | Yahoo |

## 금리: TradingView 수익률 심볼

- TVC:KR02Y / TVC:KR05Y / TVC:KR10Y / TVC:KR30Y
- TVC:US02Y / TVC:US05Y / TVC:US10Y / TVC:US30Y

close는 이 수익률 심볼의 값이며 쿠폰금리나 채권 가격을 대신 사용하지 않습니다.
change_abs는 금리 절대 변화(퍼센트포인트)입니다. 사용자 요청으로 숫자 뒤의 %p 표기는 생략하고,
상대 변화율의 %는 유지합니다. 예: (▼0.028, ▼0.75%). 계산 기준은 바꾸지 않습니다.
값 또는 증감이 누락되면 0으로 만들지 않습니다. 중복·다른 심볼 응답은 거부합니다.

공개 scanner의 global 경로에 markets=[]로 전체 자산을 명시하고 정확한 8개 심볼만 요청합니다.
누락되면 bond/cfd 경로도 각각 markets=[해당 자산]을 명시합니다. 기존 요청은 이 범위 지정이 빠져
문서의 전체 시장 조회와 같은 요청이 아니었습니다. 실응답으로 해결됐는지 확인 전에는 완료로 보고하지 않습니다.
첫 경로에서 심볼이
누락되면 같은 TradingView의 다른 자산 경로를 확인합니다. 다른 제공처로 대체하지 않습니다.
한투 금리종합·마스터·ECOS·FRED·재무부는 현재 !금리 실행 경로에서 호출하지 않습니다.

update_mode가 delayed_streaming_900이면 출처에 15분 지연을 표시합니다.
delayed_streaming은 지연 시세, 알 수 없는 갱신 모드는 지연 여부 미확인으로 표시합니다.
endofday 등 일별 전용 피드는 사용하지 않습니다. streaming 표시만으로 사용자 인증·거래소
이용권한까지 검증했다고 주장하지 않습니다. 특히 익명 조회의 지연 여부는 실제 응답으로 확인해야 합니다.

scanner가 원본 체결시각을 제공하지 않아 조회 기준은 요청을 받은 한국시간입니다.
원본 체결시각이라고 바꿔 부르지 않습니다. 출력에서 최신 조회 시각 하나만 표시합니다.

요청은 8개를 한 묶음으로 보내고 성공값은 15초 캐시합니다. 실패 시 만료된 성공값을 쓰지 않습니다.
401/403/429가 나오면 다른 경로로 우회하지 않고 중단합니다. 최소 60초 또는 숫자 Retry-After
이상 대기합니다. 로그인 쿠키를 읽거나 업로드하지 않고 캡차·인증 차단을 우회하지 않습니다.
공개 비공식 경로여서 제공처 변경·접근 제한에 따라 작동하지 않을 수 있습니다.

구현 참고(공식 보장 API가 아닌 커뮤니티 자료):
https://github.com/shner-elmo/TradingView-Screener
익명 시세와 로그인 시세의 update_mode 차이, bond/cfd 자산 scanner를 참고했습니다.

### 검증 상태

2026-10-30 클라우드에서 scanner 요청은 접속 프록시 CONNECT 403으로 차단됐습니다.
이는 TradingView 원 서버의 응답이 아니며 PC 접근 성공/실패를 판단할 근거는 아닙니다.
구현·가상 응답 테스트는 완료하되 실제 8개 시세 연결, 원본 화면과 값 비교, 피드 지연 여부는
PC 확인 전까지 미검증입니다. 자동 테스트를 실제 조회 성공으로 보고하지 않습니다.
사용자가 보낸 PC 답변에서도 전 항목 조회 불가였으며 원인은 아직 미확인입니다.
이제 전 항목 실패 시 카카오 답변 하단에 연결 상태(HTTP 상태/연결 실패/응답 불일치/심볼 미반환)를
안전한 정해진 문구로 표시합니다. 비밀값·원본 오류 본문을 전송하지 않습니다.

PC 공개 시세 검증:
```powershell
cd C:\KakaoBot\KKanggallbot
C:\KakaoBot\.venv\Scripts\python.exe -m stockbot.verify_markets 금리 --details
```

TradingView yield lookup 줄은 scanner별 성공 심볼·누락 원인·update_mode 또는 안전한
HTTP/네트워크 오류만 출력합니다. 전체 응답·헤더·쿠키·인증·계좌 자료는 출력하지 않습니다.
예전 한투 금리 파서는 회귀 테스트용으로 남아 있으나 !금리 실패 시 대체 경로가 아닙니다.

## 야간 선물

한투 공식 Postman v2.6에서 전광판 시장값은 빈 문자열=KOSPI200, MKI=미니,
KQI=코스닥150입니다. KI는 잘못된 요청값이었습니다.
분봉은 CM=야간 선물이고 자정 이후에는 24시간을 더해 입력합니다.
01:30은 전날 날짜+253000, 06시 종가는 전날 날짜+300000입니다.

실제 계약 코드는 전광판 명칭에서 찾습니다. 기본 202612, 설정 KAKAO_NIGHT_FUTURES_MONTH.
만기 후에는 202612 → 202703 → 202706처럼 다음 분기로 이동합니다. 미니·다른 상품은 제외합니다.
주간장 종가는 동일 계약의 직전 F 세션 15:45 분봉으로 검증합니다.
야간 CM의 futs_prdy_clpr는 직전 야간 종가일 수 있어 등락 계산에 사용하지 않습니다.
주간 종가가 없으면 야간 가격은 유지하고 증감 미확인으로 표시합니다.
887.90을 주간 종가 899.45와 비교하면 -11.55(-1.28%)입니다. 시가 905.22는 기준이 아닙니다.
계약+날짜별 종가를 캐시합니다. 명세·자동 테스트와 별도로 실제 F 세션 기준값 확인이 필요합니다.

공식 근거:
https://github.com/koreainvestment/open-trading-api/blob/main/legacy/postman/실전계좌_POSTMAN_샘플코드_v2.6.json

## 수급 및 기타

!수급의 시장·투자자·단위와 PC 검증은 INVESTOR_FLOWS.md를 참고합니다.
국내지수는 원본에 체결시각이 없어 조회 시각이며, 다른 값도 모두 같은 시각이라는 뜻이 아닙니다.
선물은 연속 월물 교체나 제공 지연이 있을 수 있습니다. 코인은 업비트 원화·USDT를 USD로
재표기하지 않고 실제 USD 심볼을 조회합니다. PC 과거 성공은 새 TradingView 경로의 검증을 대신하지 않습니다.
