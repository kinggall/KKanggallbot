# 시장 지표 명령어

주식 안내는 `!주갤`과 stockbot 폴더에만 둡니다. 공용 사용방법·대문에는 추가하지 않습니다.

!금리 맨 위에는 [국채 금리] 제목을 표시합니다. 전부 실패해도 제목은 유지합니다.
표출은 값 다음 줄에 공백 3개를 들여씁니다. footer는 최신 기준 시각 하나와 실제 출처를 표시합니다.
국내지수는 체결시각 필드가 없어 요청 시각이며, 다른 지표와 모두 같은 시각이라는 뜻이 아닙니다.

| 명령어 | 대상 | 현재 제공처 |
| --- | --- | --- |
| !국내지수 | 코스피·코스닥·코스피200 | 한투 우선(0001/1001/2001), 실패 시 Yahoo |
| !미국지수 | S&P500·나스닥종합·다우 | Yahoo |
| !나선 | 나스닥100 연속 선물 | Yahoo |
| !야선 | KOSPI200 분기 월물의 마지막 확인된 야간 분봉 | 한투 |
| !환율 | USD/KRW·달러인덱스 | Yahoo |
| !상품 | 금·은·WTI·천연가스·구리 연속 선물 | Yahoo |
| !금리 | 국고채 2·10·30년 다음 미국채 2·10·30년, 총 6개 | 한투 금리종합 + 한투 국채 현재가 |
| !코인 | BTC·ETH·XRP 실제 USD 시세 | Yahoo |

## 야선: 빈 응답의 근본 원인

공식 Postman v2.6의 display-board-futures 시장 구분값:
- 빈 문자열: KOSPI200
- MKI: 미니 KOSPI200
- KQI: KOSDAQ150

앞선 MKI 요청은 실제 PC에서 미니F만 반환했습니다. 이어 잘못 지정한 KI는 명세에 없는 값이었으며
PC에서 빈 output을 반환했습니다. HTTP/API 성공 여부와 계약 목록이 존재하는지는 다릅니다.
이번 수정은 시장 구분값을 빈 문자열로 바로잡고, 빈 응답을 별도 진단합니다.
공식 근거: https://github.com/koreainvestment/open-trading-api/blob/main/legacy/postman/실전계좌_POSTMAN_샘플코드_v2.6.json

기본 요청 월물은 사용자가 지정한 202612이며 환경변수 KAKAO_NIGHT_FUTURES_MONTH로 바꿀 수 있습니다.
실제 코드는 전광판 응답의 상품명과 단축코드에서 찾고 추정하지 않습니다.
미니·스프레드·옵션은 제외합니다. 3·6·9·12월 분기 월물만 선택합니다.

만기 당일 잔존일수 0이며 15:45 이후이거나 잔존일수가 음수면 다음 분기 월물로 이동합니다.
202612 → 202703 → 202706 순서이며 다음 달 월물이나 미니로 넘어가지 않습니다.
만기 행이 사라진 경우 정규 만기일인 둘째 목요일 15:45를 보조 기준으로 사용합니다.
거래소 휴일로 만기일이 이동하면 응답 잔존일수를 우선하며, 사라진 행만으로 휴일 이동까지
완전히 판정할 수는 없습니다. 실제 응답 만기 검증이 필요합니다.

분봉 명세의 시장분류는 F=주간 지수선물, CM=야간 선물입니다. 기존 F 요청도 잘못됐습니다.
CM에서는 자정 이후 입력 시간을 24시간 더해 사용합니다. 예를 들어 01:30은 전날 날짜와
253000, 야간 종가 06시는 전날 날짜와 300000입니다. 응답의 24~30시도 달력 날짜로 환산합니다.
근거는 위 공식 Postman의 inquire-time-fuopchartprice 파라미터 설명입니다.
아침에도 직전 야간 종가를 기준으로 마지막 야간 분봉을 조회합니다. 주간 가격으로 대체하지 않습니다.
야간 분봉이 없거나 계약이 다르면 조회 불가입니다. REST 경로의 야간 자료 제공과
영업일/달력일 차이는 PC 실제 응답으로 확인해야 합니다. 수정 후 실제 야선 성공은 미확인입니다.

## 국채·미국채: 한투 단일 제공처

금리종합의 표시명만 검색해서 누락을 확정하지 않습니다. 다음 한투 공식 경로를 추가했습니다.

1. 공식 `frgn_code.mst.zip`에서 국가·만기·국채 명칭을 대조해 실제 코드를 찾습니다.
   API 시장값 I를 마스터의 첫 글자와 같다고 가정하지 않습니다. 이전 I 전용 필터는 잘못된 가정이었습니다.
   파일의 실제 분류별 건수와 채권 관련 명칭을 공개 진단에 남겨 마스터 내용을 확인할 수 있게 합니다.
2. 한국어명과 영문명을 둘 다 확인하고, 불일치하면 사용하지 않습니다. 다른 나라·만기·ETF·선물 제외.
3. 해당 코드로 한투 `inquire-daily-chartprice`를 시장 I(국채)로 요청합니다.
4. 응답 `output1.ovrs_nmix_prpr`(현재가)만 금리값으로 사용합니다. 일봉 `output2` 종가를 대신 쓰지 않습니다.
5. 반환 종목코드·명칭을 다시 대조하고 현재가와 일치하는 최신 원본 날짜를 확인합니다.
6. 금리종합 값이 있는 만기도 조회해 두 값과 차이를 공개 검증 정보에 남깁니다. 더 오래된 날짜로 덮어쓰지 않습니다.

공식 근거:
- https://github.com/koreainvestment/open-trading-api/blob/main/stocks_info/overseas_index_code.py
- https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/overseas_stock/inquire_daily_chartprice
- 위 예제의 시장분류: N=해외지수, X=환율, I=국채, S=금선물.

마스터는 24시간 메모리 캐시, 다운로드 실패는 60초 재시도 제한입니다. TLS 검증을 끄지 않으며
ZIP은 메모리에서 지정 파일만 읽고 디스크에 추출하지 않습니다. 코드를 추정하거나 없던 값을 만들지 않습니다.
각 만기 최대 3개의 검증된 코드 후보만 시도합니다. 5년물은 요청·표시하지 않습니다.
이전 !국채·!미국채는 !금리 하나로 대체했습니다. 통합은 조회 실패 자체의 해결을 뜻하지 않습니다.
6개 만기의 PC 실조회 확인은 남아 있으며 가상 응답 테스트를 실제 연결 성공으로 주장하지 않습니다.

공식 API:
- GET /uapi/domestic-stock/v1/quotations/comp-interest
- TR: FHPST07020000
- FID_COND_MRKT_DIV_CODE=I, FID_COND_SCR_DIV_CODE=20702
- FID_DIV_CLS_CODE=1, FID_DIV_CLS_CODE1=빈 문자열

공식 예제:
https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/domestic_stock/comp_interest

output1·output2에서 상품명으로 국가와 2·5·10·30년 만기를 식별합니다.
bond_mnrt_prpr는 채권금리 현재가, bond_mnrt_prdy_vrss는 전일 대비이며 부호 필드를 반영합니다.
금리 자체는 %, 절대 증감은 %p입니다. 채권 가격·선물·ETF·다른 나라·다른 만기를 섞지 않습니다.

명령어는 ECOS/FRED/재무부/TradingView를 호출하거나 실패 시 대체하지 않습니다.
기존 일별 파서 함수는 회귀 테스트를 위해 남아 있으나 두 명령어의 실행 경로와 분리돼 있습니다.

중요: 공식 응답 명세는 stck_bsop_date(영업일자)를 제공하지만 체결시각·확정 갱신주기를
명시하지 않습니다. 따라서 이 API가 현재 시장 금리와 일치하는지는 실제 응답을 비교해야 합니다.
단순 HTTP 성공으로 틱 실시간이라고 주장하지 않습니다. 데이터 날짜는 수신 영업일자를 그대로
표시하며 현재 시각으로 바꾸지 않습니다. 클라우드에는 PC 한투 인증이 없어 실제 값 대조는 미완료입니다.

## PC 공개 시세 검증

```powershell
C:\KakaoBot\.venv\Scripts\python.exe -m stockbot.verify_markets 금리 --details
```

--details는 공개 가격·전일 기준값·출처와 금리 상품명·자료코드·영업일자, 마스터의 후보 코드와 이름,
현재가와 금리종합 값의 비교 결과를 표시합니다. 응답 섹션의 행 수·필드명도 표시해 누락 구조를 확인합니다.
계좌 조회·인증값 출력·카카오 전송은 하지 않습니다. 상품명 매핑이 누락되면 검증용
허용 필드만 출력하여 실제 응답으로 수정할 수 있게 합니다. 전체 응답/헤더는 출력하지 않습니다.
중첩된 output 및 이름/값/날짜가 함께 붙은 명시적 숫자 접미사 필드도 읽습니다. 필드가 어긋난 행의
위치를 추정해 옮기지는 않습니다. 원본 체결시각과 실시간 갱신 주기는 여전히 명세상 미확정입니다.

국내지수·미국 지수·환율·상품·USD 코인은 이전 PC에서 조회 성공했습니다.
이전 FRED/ECOS 일별 금리 성공은 실시간 요구 충족의 증거가 아니며 더 이상 해당 명령어에 사용하지 않습니다.
2026-10-30 후속 PC 검증에서 야선은 A01612, 06:00 값 915.10 / 전일 기준 951.00으로 성공했습니다.
금리 응답은 미국 10년T-NOTE·30년T-BOND를 포함하지만 기존 정규식이 년 다음 T를 거부했습니다.
이 인식 오류를 수정했습니다. 첨부 응답에 미국 2·5년은 없고, 국내 일부 행은 명칭/금리/날짜
필드가 어긋나 있어 안전하게 거부합니다. 이 자료를 위치 추정으로 복원하거나 없는 만기를 만들지 않습니다.
국내 30년은 정상 행으로 응답했습니다. 위 세 정상 금리의 기준일은 2026-10-29이며 이 사실만으로
실시간 갱신을 증명할 수 없습니다. 현재 요청인 6개 만기의 실제 연결도 아직 완료로 보지 않습니다.
