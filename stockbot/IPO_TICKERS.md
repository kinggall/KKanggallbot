# 보유·공모주 종목코드

- 티커가 빈 값/미확인/코드 미확인/unknown이면 같은 코드로 중복 제거하지 않고 종목명으로 구분합니다.
- 미확인 보유의 정확한 종목명으로 한투 공개 코스피·코스닥 마스터에서 후보를 찾습니다.
- 후보가 하나일 때 네이버 stock/basic API의 itemCode·nationType=KOR·stockName을 대조한 뒤 사용합니다.
- 종목명 일부·비슷한 회사·추정 코드로 할당하지 않습니다. 조회 실패나 모호함은 코드 미확인으로 남깁니다.
- 상장정보에 아직 없는 공모주를 임의로 상장/비상장으로 분류하지 않습니다.
- 오아시스는 사용자가 비상장으로 확인했으므로 기존 UNLISTED_NAMES 정책을 유지하며 API 조회를 건너뜁니다.

확인 성공은 한국 날짜 당일에만 재사용합니다. KST 날짜가 바뀌면 마스터와 종목 API를 다시 확인합니다.
같은 날에 아직 없었던 공모주도 5분 후 재조회하여 당일 중 추가된 종목을 찾습니다.
미확인 종목이 여럿이어도 마스터는 5분간 공유합니다. 제공처의 상장정보 반영 전에는 코드를 확정하지 않습니다.
실제 회사의 신규 티커를 하드코딩하지 않습니다. PC에서 해당 종목 API 조회가 성공했는지는 별도 확인이 필요합니다.

목록과 종목별 상세 모두 같은 보완 코드를 사용합니다. 원본 Domino JSON/DB·평단·수익률·거래원장은 수정하지 않습니다.
보유수량·계좌·개인 자료는 새 파일로 저장하지 않습니다. 확인 코드는 프로세스 메모리에만 유지합니다.
이미 유효한 티커의 거래소 접두사와 미국 종목 표시는 보존합니다. !실현 목록도 미확인 코드로 서로 숨지 않습니다.

일반 보유 목록/상세 명령에서 필요할 때 갱신하며 별도 스케줄러·계좌 API·주문 API는 추가하지 않습니다.
