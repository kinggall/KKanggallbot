# 깡갤봇

카카오톡 메시지에 자동으로 답변하는 봇입니다.

`!드랍 [해역/함선명]`은 칸로그에 기반한 일반 해역 37곳의 드랍률과 함선별 위치를 보여줍니다. `!드랍 55p`, `!드랍 5-5 S`, `!드랍 7-5-1`, `!드랍 후부키`를 지원합니다. `!한정드랍`은 한정 드랍이 확인된 함선을 함종별로 모아 보여줍니다. PC 저장 자료를 사용하고 전체 해역을 4시간마다 순차 갱신합니다. [KANLOG_DROPS.md](KANLOG_DROPS.md)에 수집·검증 방식을 기록했습니다.

## 드랍 정보 출처 / ドロップ情報の出典

드랍 정보는 [艦ろぐ（칸로그）](https://kanlog.info/) 운영자님의 허락을 받아 수집·활용합니다. 유용한 정보를 제공하고 이용을 허락해주신 운영자님께 감사드립니다. 서버 부담을 줄이기 위해 일정 간격으로 자료를 수집하고, 저장된 데이터로 검색 결과를 제공합니다.

ドロップ情報は、[艦ろぐ](https://kanlog.info/)の運営者様の許可を得て取得・利用しています。有益な情報の提供とデータ利用のご許可に、心より感謝申し上げます。サーバーへの負荷を抑えるため、一定の間隔を空けて情報を取得し、保存したデータを用いて検索結果を提供しています。

`!개발 장비명`은 장비 별명과 `#번호`를 지원하며, 최적 레시피와 필요한 경우 범용 레시피를 보여줍니다. 자원 순서는 연료 / 탄약 / 강재 / 보크사이트입니다. 계산은 PC에 포함된 데이터로 수행합니다.

`!레시피 리슐리외 10/30/20/10`은 지정한 함선·자원의 모든 개발 결과와 실패율을 보여줍니다. 함선 별명도 지원합니다. `!레시피 푸릉이 10/30/20/10`처럼 입력하면 테루즈키의 아키즈키급 개발 그룹을 자동으로 사용합니다. 개장형에 따라 그룹이 다를 수 있으므로 원하는 개장형을 명시하세요.

`!초기장비 유바리`는 전체 개장형의 초기 장비를 보여줍니다. 별명도 지원하며, 개수 장비에는 `★7`처럼 표시합니다. 초기 장비가 없는 형태도 생략하지 않습니다. 자료 출처와 검증은 [INITIAL_EQUIPMENT_DATA.md](INITIAL_EQUIPMENT_DATA.md)에 기록했습니다.

`!개수 장비명`은 단계별 자재·나사와 확정 비용, 소모아이템, 2번함·요일, 변환 경로를 보여줍니다. 별명·`#번호`도 지원하며, 재료가 같은 연속 단계와 요일이 같은 개장형을 묶어 표시합니다. 데이터는 74식 공개 자료를 저장소에 포함해 PC에서 읽습니다. 출처와 표시 기준은 [IMPROVEMENT_DATA.md](IMPROVEMENT_DATA.md)를 참고하세요.

## Windows에서 GitHub 자동 업데이트

Git for Windows가 설치되어 있고 봇 가상환경이 `C:\KakaoBot\.venv`에 있다고 가정합니다. 기존 `C:\KakaoBot` 파일은 그대로 둔 채 저장소를 별도 폴더에 한 번만 내려받습니다.

```powershell
git clone https://github.com/kinggall/KKanggallbot.git C:\KakaoBot\KKanggallbot
powershell -NoProfile -ExecutionPolicy Bypass -File C:\KakaoBot\KKanggallbot\watch_bot.ps1
```

감시 PowerShell 창은 켜 두어야 합니다. 봇의 Python 창은 숨겨지고, 30초마다 하는 GitHub 확인은 화면에 출력되지 않습니다. 새 커밋이 있으면 실행 중인 `bot.py`를 멈춘 뒤 업데이트하고 다시 실행합니다. 봇이 종료되면 같은 버전을 반복 실행하지 않고 로그를 확인하도록 알립니다. 감시를 종료하려면 PowerShell 창에서 `Ctrl+C`를 누르세요. Iris는 별도로 계속 실행 중이어야 합니다. 실행 로그는 `C:\KakaoBot\logs`에 저장됩니다.
